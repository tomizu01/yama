■山手線大冒険ゲーム

# 概要

・疑似３Dレトロレースゲーム風アプリ
・仮想山手線１週コース
・BLEデバイスと連携
　次の2パターンのどちらか
　- Cycling Speed/Cadence（負荷無視）
　- Cycling Power + デバイスが対応していればFE-C over BLE（負荷考慮）
　所持デバイスによりユーザーが選択できる
　実際に走行した分だけ自分が進む
・操作は、フィンガーマウスのポインタにより自転車の左右移動のみ可能
　※室内とはいえ複雑な操作は危ない
　※ローラー台では操作しない。ダイレクトドライブのバランスの安定した環境でのみ使用する

# 実装フェーズ

1. レトロゲーム風レース

　- まずはゲームの基礎のレース部分を動かす
　- プレイヤーが走ると、奥から避けれる程度にランダムに障害物が降りてくる（障害物は止まっているが相対的に降りてくるように見える）
　- 遠近法により、遠くの障害物は小さく、近づくと大きくなる
　- 動きは、マウスのx座標で操作。プレイヤーよりマウスカーソルが左なら左に動く。右なら右に動く。y座標は無視
　- この段階では常に走り続ける
　- 障害物が一番手前まで降りてきたときにプレイヤーとぶつかると、速度が落ちる

2. BLE連携

　- 開始時に方式選択、それにあわせてデバイスを検索
  - ユーザーがデバイスを確認して接続操作
　- 対象デバイスから、必要な情報を取得してゲームに反映させる

3. ステージ作成

　- 山手線の１駅分の移動が１ステージ。東京駅スタート＆最終ゴール
　- 駅の名前を使うだけで、ステージ内容や背景に変更はない
　- 各ステージの距離はほぼ駅間の距離に合わせる
　- ステージ毎にノルマタイムあり。勾配設定あり
　- ノルマタイムに間に合えば"win", 間に合わなければ"lose"
　- ステージの合間に成績表（ステージ毎のwin/loseが一覧）
  - ステージ開始画面、完了画面をつける

4. ブラッシュアップ

　- 画面の見た目向上
　- ステージギミックの追加
　- 走行ログの保存

など
